# Decisions

What has already been decided, so nobody — human or agent — relitigates it.

**Every decision needs a source.** A decision with no source is a memory, and
memories are what this file exists to replace. `Source:` is not optional: the
`/throughline:check` command counts the ones missing it.

Format:

```
## YYYY-MM-DD — <the decision, in one line>
**Why:** <the reasoning that would otherwise be lost>
**Source:** <link to the email / Slack thread / PR / meeting, or "conversation with <name>">
```
