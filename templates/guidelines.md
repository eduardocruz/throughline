# Active guidelines

Maximum **three**. Rules your AI agent must respect in every recommendation.

These are extracted from real events, never written abstractly. A guideline that
did not come from something that actually happened is a preference, and the
agent should not be made to carry it.

Good (came from an incident):
- "Always check the provider before claiming a payment settled."
- "Don't deploy on Friday afternoon."
- "Never run migrate:fresh anywhere client data lives."

Bad (abstract):
- "Write clean code."
- "Be careful with the database."
